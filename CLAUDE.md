# Claude Instructions

## All Changes
- Log any changes to the top of CHANGELOG.md file with a date
- When fufilling a TODO task remove it from the TODO.md when completed

## Committing
- Commit after each logical unit of work (feature, bug fix, refactor step) — don't batch unrelated changes into one commit.
- Write commit messages that explain *why*, not just what changed.

## Tests
- Add or update tests for any change in behavior or bug fix before committing that change.
- A bug fix without a regression test is incomplete.
